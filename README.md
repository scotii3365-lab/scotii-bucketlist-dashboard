# 🗺️ Scotii's Retirement Explorer Dashboard & Weekly Timetable

스카티(Scotii)님의 은퇴 탐험 버킷리스트 및 주간 데일리 타임테이블(월~일) 관리 웹 대시보드입니다.

## ✨ 주요 기능
- **버킷리스트 관리:** 주거 & 정착, 건강 & 여가, 배움 & AI, 봉사 & 재능기부 카테고리별 버킷리스트 관리
- **주간 데일리 타임테이블 (월~일):** 버킷리스트 항목을 월요일부터 일요일까지 시간대별 루틴으로 매핑
- **실시간 데이터 보존:** LocalStorage를 이용해 체크리스트 달성률 및 주간 일정이 안전하게 보존됨
- **Claude 스타일 UI:** 다크네이비 & 코랄 테마, 반응형 디자인, 다크/라이트 모드 지원
